# 粘不粘

一款面向 Windows 的本地素材粘贴板，用来收集设计参考图和常用文字提示词。素材保存在自己选定的文件夹里，不上传云端，也不会自动记录全部剪贴板历史。

## 下载与使用

从本仓库的 **Releases** 下载最新的 Windows 安装包或免安装版。首次打开时选择一个本机文件夹作为素材库；之后可在设置中迁移到其他文件夹。

- 复制截图、网页图片或文字后，按 `Ctrl+Alt+S` 收集，或在面板中点击“保存剪贴板”。也可以直接写文字、导入或拖入本机图片。
- 点击桌面的悬浮图标展开或收起面板，拖动图标可改变位置；也可以按 `Ctrl+Alt+V` 呼出。面板与图标都保持置顶。
- 在“全部、文字、图片、常用”中查找素材；可搜索名称、正文和标签，并为素材置顶、加入常用或编辑文字。
- 每条素材单独复制。多选和全选只用于批量管理，不会批量复制。
- 删除先进入回收站，可恢复；30 天后自动清除，也可手动彻底删除或清空回收站。

设置中的快捷键框支持**点击后直接按组合键录制**，按 `Esc` 取消；不需要快捷键时点击“清除”，留空也可保存。快捷键被占用时，应用会提示重新设置。

## 数据保存

素材库文件夹包含 `library.sqlite` 和 `images/`。提示词、名称、标签及状态保存在数据库中，图片保存在 `images/`。换电脑时复制**整个素材库文件夹**，并在新电脑首次打开时选中它。安装包不包含个人素材。

本应用仅支持 Windows。它不内置截图工具，不读取微信聊天数据库，也不会自动收集每次复制的内容。图片能否粘贴到目标软件，取决于目标软件支持的剪贴板格式。

## 从源码运行

需要 Windows、Node.js 和 npm。

```powershell
npm ci
npm start
```

`npm run check` 检查 JavaScript 语法，`npm test` 运行素材库测试。`npm run installer` 在 `installer/` 生成安装包；`npm run preview` 在 `preview/` 生成免安装版；`npm run package` 在 `dist/win-unpacked/` 生成未压缩的应用目录。构建输出不会提交到 Git。
